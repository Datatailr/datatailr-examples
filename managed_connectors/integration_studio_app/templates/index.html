Slack, HubSpot, and GitHub Organization are shared from administrator-managed credentials to users allowed into the app. GitHub content is fetched live through short-lived installation tokens and is not added to the knowledge index. Gmail, Outlook, and Zoom are fetched live for the signed-in user and never written to the knowledge index.

Admin

Shared connector credentials and personal OAuth applications for this workspace.

Shared secrets are encrypted with a master key held in Datatailr secure KV and are never returned by the API. Gmail is configured privately by each user. Outlook and Zoom OAuth applications are configured once here; each user's delegated tokens remain private to that user. GitHub uses one administrator-installed organization app and only sees repositories selected for that installation.
