# Datatailr System Builder

Prefer the `/dt-system` command family for this workflow.

## Golden path

- `/dt-system new` — scaffold a new system, spawn subagents, deploy, and summarize results.

## Expert commands

- `/dt-system scaffold <system-slug>`
- `/dt-system delegate <system-slug>`
- `/dt-system deploy <system-slug>`
- `/dt-system status <job-name>`
- `/dt-system logs <job-name>`
