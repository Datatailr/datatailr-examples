    Examples

    The platform adds your user name to each request. The service does not check the API key, but the openai client needs a value. A client outside the platform must prove who you are. The outside example sends the login of the Datatailr CLI: install the datatailr package and run datatailr login once.

    An API token of your user works too. The platform reads it only from the query argument __datatailr_user_cookie__ of the URL, not from a cookie and not from the Authorization header. The script chat.py sends it that way when you set LLM_TOKEN.
